Build in debug using SFML 2.6.2.

 - Left Click shoot

Note:
The BUILD folder should be kept inside the same folder as the as the assets folder, other wise all text will become
unintelligible and file handling will not work. This may be humorous but is absolutely unintentional. Please keep this 
in mind, and run the game in the forementioned folder.
